# Design

## ALWAYS

- Use tailwindcss classes for styling whenever possible
- Limit custom CSS to only what is necessary and cannot be achieved with tailwind
- Use semantic HTML elements (e.g., `<header>`, `<nav>`, `<main>`, `<footer>`) to structure the page
- Use tailwind breaking points for responsive design (e.g., `sm:`, `md:`, `lg:`, `xl:`)
- Ensure accessibility by using appropriate ARIA attributes and semantic HTML
- Use Lucide icons for visual elements where appropriate
